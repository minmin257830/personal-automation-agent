# Recap video — မြန်မာလို ပြန်ဆို + အသံသွင်း + လူလို edit

မူရင်း video + မင်းရဲ့ မြန်မာအသံဖိုင် ပေးလိုက်ရင် `edit_recap.py` က
လူလို edit လုပ်ပေးတယ် — မလိုတဲ့ အခန်းဖြတ်၊ မူရင်းအသံဖြုတ်၊
မင်းအသံနဲ့ အစားထိုး၊ အသံညှိ၊ မြန်မာစာတန်းထိုး ထည့်၊ အစ/အဆုံး fade။

## လိုတဲ့ ဖိုင် (တစ်ပုဒ်ကို)

| ဖိုင် | ဥပမာ | မှတ်ချက် |
|---|---|---|
| မူရင်း video | `original.mp4` | ဖိုင်ဖြစ်ဖြစ် link ကနေ ဒေါင်းထားတာဖြစ်ဖြစ် |
| မြန်မာအသံ | `voice-my.m4a` / `.mp3` / `.wav` | မင်းကိုယ်တိုင် အသံသွင်းထားတာ |
| စာတန်းထိုး (ရှိရင်) | `subs-my.srt` | မြန်မာစာ၊ အချိန်ကိုက် |
| ဖြတ်မယ့် အခန်း (ရှိရင်) | `cuts.txt` | တစ်ကြောင်းကို `0-12.5` လို၊ စက္ကန့်နဲ့ |

## သုံးနည်း (boxes.dev box ပေါ်မှာ — ffmpeg က manifest မှာ ပါပြီးသား)

```bash
python3 recap-video/edit_recap.py --video original.mp4 --voice voice-my.m4a \
  --subs subs-my.srt --cuts cuts.txt --out recap-my.mp4
```

`--subs` / `--cuts` မပေးလည်း ရတယ်။ Video က အသံထက် ရှည်ရင်
အသံအတိုင်း ဖြတ်ပေးတယ် (`--mode keep-video` ဆို video အပြည့်ထား၊
အသံကုန်ပြီးနောက် တိတ်ဆိတ်ထားပေးတယ်)။

## စမ်းပြီးသား (2026-11-25, ဒီကွန်ပျူတာ — ffmpeg 8.1.2)

- 20 စက္ကန့် video + 12 စက္ကန့် အသံ + cuts `0-5`, `8-15` + မြန်မာစာတန်းထိုး
- ထွက်: `recap-my.mp4` 12.0 စက္ကန့်, h264 + aac — `test/frame.png` မှာ
  "မင်္ဂလာပါ မြန်မာပြည်" စာတန်းထိုး မြင်ရတယ်။
- Test ဖိုင်တွေ `test/` ထဲမှာ ရှိတယ်။

## မဖြေရသေးတဲ့ မေးခွန်း (မင်းအဖြေမှ pipeline အပြည့်ဖြည့်မယ်)

2. မူရင်း video က ဖိုင်လား link လား?
3. အသံက မင်းကိုယ်တိုင် သွင်းတာလား, AI အသံနဲ့ လုပ်ပေးရမှာလား?
